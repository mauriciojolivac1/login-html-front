# login-html-front

Proyecto ejemplo: página de login en HTML, CSS y JavaScript nativos (JWT vía `fetch`).

## Inicio rápido

Instala dependencias y ejecuta tests: `npm install` y `npm test`.

Para ver la UI en el navegador, sirve la raíz del repo con un servidor HTTP (por ejemplo `python -m http.server 8000`) y abre la URL indicada.

Más detalle (API, metas de configuración): [docs/README.md](docs/README.md).
